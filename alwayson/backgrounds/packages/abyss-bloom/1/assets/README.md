# Abyss Bloom assets

Abyss Bloom uses four paired visual states for slow ambient crossfade animation.

Base frame:

- `AbyssBloomLandscape.png`
- `AbyssBloomPortrait.png`

Additional animation frames:

- `AbyssBloomLandscape1.png` / `AbyssBloomPortrait1.png`
- `AbyssBloomLandscape2.png` / `AbyssBloomPortrait2.png`
- `AbyssBloomLandscape3.png` / `AbyssBloomPortrait3.png`

Target sizes:

- Landscape: 2560 × 1440
- Portrait: 1440 × 2560

Use PNG, sRGB, no embedded text, and keep the composition safe around the center so the clock remains readable. The states should stay visually close enough to support long crossfades rather than feel like separate slides.
